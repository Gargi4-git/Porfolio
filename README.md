# Gargi Padate · Personal Portfolio

A custom editorial-style, responsive portfolio built using plain HTML, CSS and JavaScript. No build step or framework required.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish with GitHub Pages
1. Upload the contents of this folder to your existing `Porfolio` GitHub repository (replace the existing HTML/CSS/JS files).
2. In repository Settings → Pages, select **Deploy from a branch**, `main`, `/ (root)`.
3. Your site will appear at `https://gargi4-git.github.io/Porfolio/` after GitHub finishes publishing.

## Customize
- `index.html`: sections, project copy, social links.
- `styles.css`: colors, typography, responsive layout.
- `script.js`: mobile navigation and reading progress.
- `photo.jpg`: hero portrait (retained from original).
- `cv2.pdf`: résumé link (retained from original; verify it is your latest version).
- `CERTIFICATES/`: original certificate assets, retained unchanged.

The portfolio does not include a fake contact form; the email CTA opens the visitor's mail app. Project descriptions are based on the supplied technical profile, and research metrics are labeled as reported results. Add verified project/demo links when available.
