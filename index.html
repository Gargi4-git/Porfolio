Projects

Research Project / Published Paper

Parkinson's Disease Detection Using Keystroke Dynamics

June 2025 – July 2025

Built a non-invasive AI system to detect early-stage Parkinson's disease by analysing a user's typing behaviour (keystroke dynamics). Applied PSO (Particle Swarm Optimisation) for intelligent feature selection and trained an Ensemble Voting Classifier for high-accuracy predictions. Deployed as a Flask web application enabling real-time screening accessible via browser.

Key Outcomes
  • Published in Springer Nature (Atlantis Press), January 2026
  • Achieved state-of-the-art classification performance using ensemble methods and PSO-based feature selection
  • Deployed as a fully functional Flask web app for real-time, non-invasive Parkinson's screening
  • Demonstrates a low-cost, accessible alternative to traditional clinical diagnostic methods
Python Scikit-learn PSO Ensemble Classifier Flask HTML/CSS NumPy Pandas

AgriShield — Smart Pest Control Using YOLOv11

Mid-2025 (Published Dec 2025)

Developed a real-time agricultural pest detection and monitoring system using the YOLOv11 object detection model integrated with IoT hardware (ESP32-CAM + PIR sensor). The system detects pests in crop fields with high accuracy and triggers automated alerts, enabling AI-driven smart agriculture. The research was presented at an IEEE international conference and the underlying system was granted a patent.

Key Outcomes
  • Achieved 85% mAP, 88% precision, and 82% recall on a custom agricultural pest dataset
  • Published at IEEE ICICIS, December 2025
  • Granted patent: "An Agricultural Pest Detection and Monitoring System"
  • Real-time inference on edge hardware (ESP32-CAM) for low-resource rural settings

Research Project

EEG-Based Epilepsy Detection System

July 2025 – October 2025

Developed a noise-robust epilepsy detection model that processes EEG (electroencephalogram) brain signals to classify epileptic episodes. Used hybrid feature extraction techniques and a Stacking Ensemble classifier to maximise accuracy across two benchmark datasets. Integrated SHAP-based interpretability for clinical transparency and deployed the model on a Raspberry Pi for real-time edge inference.

Key Outcomes
  • Achieved 98.7% accuracy on the BEED dataset and 94.6% accuracy on the Bonn dataset
  • Deployed on Raspberry Pi for real-time, on-device epilepsy detection
  • Integrated SHAP for interpretable, clinically meaningful predictions
  • Hybrid feature extraction outperformed single-method baselines
Python EEG Processing Stacking Ensemble SHAP Raspberry Pi NumPy SciPy Scikit-learn
